# SPDL1-IPMS — code and processed data for the human Spindly IP-MS dataset

Code, pipeline inputs and processed tables accompanying the Data Descriptor
*"Proteomic dataset of human Spindly post-translational modifications and
interactome in mitotic cells"* (submitted to *Scientific Data*).

The mass spectrometry data (raw files, Proteome Discoverer result files,
mzIdentML, peptide/protein exports and SDRF) are deposited in the
ProteomeXchange Consortium via PRIDE under accession
**[PXD085140](https://www.ebi.ac.uk/pride/archive/projects/PXD085140)**.

## Study design (summary)

Endogenous Spindly (SPDL1, UniProt Q96EA4) was immunoprecipitated from HCT116
and hTERT-RPE1 cells arrested in prometaphase with nocodazole (NZ), with or
without okadaic acid (OK), and from a λ-phosphatase-treated control. Six
LC-MS/MS acquisitions (Q Exactive Plus) were searched with Proteome
Discoverer 2.2 / Sequest HT against a targeted Spindly database and against
the UniProt human reference proteome.

| Run | Cell line | Condition | PRIDE raw file |
|-----|-----------|-----------|----------------|
| R1 | hTERT-RPE1 | NZ | SPDL1_R1_20220218_NZ.raw |
| R2 | hTERT-RPE1 | NZ + OK | SPDL1_R2_20220218_NZ_OK.raw |
| R3 | HCT116 | NZ | SPDL1_R3_20220324_NZ.raw |
| R4 | HCT116 | NZ + OK | SPDL1_R4_20220324_NZ_OK.raw |
| R5 | HCT116 | NZ + OK (bead eluate, control batch) | SPDL1_R5_20220127_NZ_OK.raw |
| R6 | HCT116 | NZ + λ-phosphatase (bead eluate) | SPDL1_R6_20220127_NZ_PPasa.raw |

## Repository layout

```
code/
  analyze_hspindly_ptms.py      Parses the proteome-wide Excel exports (data/), maps phospho and
                                GlyGly modifications to Q96EA4 residue numbers, builds the
                                co-IP interactome table and per-run QC counts.
  extract_pdresult_evidence.py  Reads the targeted-search .pdResult files from PRIDE (SQLite) and
                                regenerates the PSM-level evidence table, Table 3 (High-confidence,
                                unambiguously localised PSMs per site and run) and the Y508H
                                (rs3797713) variant counts.
  read_pdresult.py              Dumps acquisition metadata and search parameters of any .pdResult.
  read_raw_headers.py           Reads instrument and LC/MS method parameters from Thermo .raw
                                headers without vendor libraries.
  make_manuscript_figures.py    Builds Figures 1-3 (phosphosite matrix, domain map, AlphaFold model).
  spindly_alphafold.pml         PyMOL script for a 3D render of AF-Q96EA4-F1-model_v6.
data/                           The twelve Proteome Discoverer Excel exports used as pipeline input
                                (see data/README.md).
results/                        Tables generated by the scripts (committed for convenience).
figures/                        Figures generated by make_manuscript_figures.py.
```

## Requirements

Python ≥ 3.9. `extract_pdresult_evidence.py`, `read_pdresult.py` and
`read_raw_headers.py` use only the standard library; the other scripts need
the packages in `requirements.txt`.

```bash
pip install -r requirements.txt
```

## Reproducing the results

```bash
# 1. Pipeline on the proteome-wide exports shipped in data/
python code/analyze_hspindly_ptms.py --data-dir data --out-dir results

# 2. PSM-level evidence from the targeted searches (download PXD085140 first;
#    the folder may be flat or contain sub-folders)
python code/extract_pdresult_evidence.py --pride-dir PATH/TO/PXD085140 --out-dir results

# 3. Figures
python code/make_manuscript_figures.py --out-dir figures

# Optional: inspect metadata of individual files
python code/read_pdresult.py PATH/TO/SPDL1_R1_20220218_targeted_NZ.pdResult
python code/read_raw_headers.py PATH/TO/PXD085140
```

All scripts are deterministic: the same inputs give identical tables.

## Output files

| File | Content |
|------|---------|
| `results/spindly_sites_all.csv` | Every phospho/GlyGly PSM mapped to a Spindly residue (proteome-wide search), with peptide, confidence, XCorr and source file. |
| `results/phospho_site_matrix.csv`, `results/ubi_site_matrix.csv` | Site × condition occupancy matrices. |
| `results/interactome_all_runs.csv` | Co-immunoprecipitated proteins per run. |
| `results/run_summary.csv` | Per-file counts (protein groups, Spindly peptides, localised sites). |
| `results/spindly_phosphosite_evidence_pdResult.csv` | All Medium/High phospho-PSMs on Spindly from the targeted searches (146 rows). |
| `results/table3_high_unambiguous_counts.csv` | High-confidence, unambiguously localised PSMs per site and run (Table 3). |
| `results/y508h_variant_counts.csv` | High-confidence PSMs covering residue 508, H508 vs Y508. |
| `results/run_metadata.json` | Acquisition date, instrument and search parameters per run. |

## Notes and limitations

* Searches were validated with fixed XCorr thresholds (Fixed Value PSM
  Validator); no target–decoy search was run, so no FDR can be given.
  Confidence classes are those assigned by Proteome Discoverer.
* No site-localisation scoring (ptmRS) was run. Localisation is reported as
  Proteome Discoverer's `PsmAmbiguity` flag; five sites (T509–K518) lie in one
  tryptic peptide (residues 504–518) and the per-residue calls in
  `make_manuscript_figures.py` (`CURATED`) come from manual spectral inspection.
* H517 (phospho-His) and K518 (phospho-Lys) are non-canonical, acid-labile
  modifications and should be regarded as tentative.
* The Q96EA4 sequence is embedded in the code (MD5-checked), so no network
  access is needed at run time.
